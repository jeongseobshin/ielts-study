# IELTS 7.0 · 28일 스프린트

28일 학습 트래커 + CBT 형식 연습 + AI 튜터 피드백 + 자동 오답노트.

프론트엔드는 `index.html` 한 파일이고, AI 튜터만 서버리스 함수 하나를 씁니다.

## 배포: 두 가지 경로

AI 튜터를 쓸지에 따라 방법이 갈립니다. **드래그 앤 드롭으로는 AI 튜터가 동작하지 않습니다** — Netlify Drop은 정적 파일만 게시하고 서버 함수를 실행하지 않기 때문입니다.

| | 드래그 앤 드롭 | CLI 또는 Git |
|---|---|---|
| 트래커·밴드 계산기·타이머 | 동작 | 동작 |
| CBT 리딩 (채점까지) | 동작 | 동작 |
| **AI 튜터 피드백** | **안 됨** | 동작 |
| 걸리는 시간 | 1분 | 5분 |

### 경로 A — 드래그 앤 드롭 (AI 없이 먼저 써보기)

1. `ielts-sprint.zip`의 **압축을 풀어** `ielts-sprint` 폴더를 만듭니다
2. https://app.netlify.com/drop 에 그 **폴더를** 끌어다 놓습니다 (zip 그대로 말고 폴더를)
3. 주소가 즉시 발급됩니다

AI 채점 버튼을 누르면 "Netlify에 배포하고 ANTHROPIC_API_KEY를 설정하세요"라는 안내가 뜹니다. 나머지 기능은 전부 정상입니다.

### 경로 B — CLI (AI 튜터 포함, 권장)

```bash
npm install -g netlify-cli
cd ielts-sprint
netlify login
netlify deploy --prod
```

배포 후 API 키를 등록합니다.

```bash

netlify deploy --prod          # 환경변수 반영을 위해 한 번 더
```

## AI 튜터 설정

AI 튜터는 **Anthropic(Claude)** 또는 **Google(Gemini)** 중 하나를 골라 쓸 수 있습니다. 환경변수 `AI_PROVIDER`로 선택합니다.

| | Anthropic (기본) | Gemini |
|---|---|---|
| 무료 등급 | 없음 (종량제만) | **있음** (무료 티어) |
| 채점 품질 | 안정적 (특히 Writing) | 준수, 모델·설정에 따라 편차 |
| 무료로 개인 학습 | ❌ | ✅ 한도 내 가능 |

### 1. API 키 발급

- **Anthropic**: https://console.anthropic.com 에서 키 발급. **Claude 앱 구독(Pro/Max)과 별개의 유료 종량제**로, 콘솔에서 크레딧을 충전해야 동작합니다.
- **Gemini**: https://aistudio.google.com/apikey 에서 키 발급. **무료 티어**가 있어 개인 학습 규모(하루 에세이 몇 편 + 리딩 해설)면 무료 한도 안에서 돌아갈 가능성이 큽니다. 단, 무료 티어는 보통 **주고받은 내용을 Google이 모델 개선에 사용**할 수 있으니, 본인 에세이·스크립트가 학습에 쓰이는 게 꺼려지면 결제(유료 티어)를 켜세요.

### 2. 환경변수 등록

Netlify → Site configuration → Environment variables

**공통**

| 변수 | 필수 | 설명 |
|---|---|---|
| `AI_PROVIDER` | 선택 | `anthropic`(기본) 또는 `gemini` |
| `TUTOR_PASSCODE` | 선택 | 설정하면 이 값을 아는 사람만 튜터를 쓸 수 있음 |

**Anthropic을 쓸 때** (`AI_PROVIDER=anthropic` 또는 미설정)

| 변수 | 필수 | 설명 |
|---|---|---|
| `ANTHROPIC_API_KEY` | 필수 | 발급받은 키 |
| `TUTOR_MODEL` | 선택 | 기본 `claude-sonnet-5` |

**Gemini를 쓸 때** (`AI_PROVIDER=gemini`)

| 변수 | 필수 | 설명 |
|---|---|---|
| `GEMINI_API_KEY` | 필수 | 발급받은 키 |
| `GEMINI_MODEL` | 선택 | 기본 `gemini-2.5-flash`. `gemini-2.5-pro`로 올리면 품질↑·비용↑ |

환경변수를 바꾼 뒤에는 **반드시 재배포**해야 반영됩니다.

> Gemini 2.5 계열은 기본으로 '사고(thinking)'가 켜져 출력 토큰을 소모합니다. 이 앱은 구조화 채점이 잘리지 않도록 **thinking을 꺼서** 호출합니다(pro는 API 제약상 최소값). 그래서 `gemini-2.5-flash` 같은 flash 모델이 가장 잘 맞습니다.

### 3. 비용 감각

- **Anthropic**: Writing 에세이 1편 채점은 대략 입력 1천 + 출력 1~2천 토큰 수준. 하루 에세이 2편 + 리딩 해설을 28일 돌려도 통상 몇 달러 범위입니다. https://claude.com/pricing
- **Gemini**: 무료 티어는 분당·하루 요청 수 제한 안에서 무료. 초과하면 종량제이며 flash 계열은 저렴한 편입니다. 「내 문제집(PDF)」 변환은 한 번에 토큰을 많이 쓰니, 무료 티어라면 지문을 하나씩 나눠 변환하세요. https://ai.google.dev/pricing

무료 한도·모델명·가격은 자주 바뀌니 실제 수치는 각 공식 페이지에서 확인하세요.

### 4. 공개 URL이 걱정된다면

이 사이트를 배포하면 주소를 아는 사람은 누구나 사용자님 API 키로 튜터를 호출할 수 있습니다. 두 가지 방어책이 들어 있습니다.

- **시스템 프롬프트가 서버에 고정**되어 있습니다. 클라이언트는 `task`와 데이터만 보내며, 프롬프트를 바꿔 범용 챗봇으로 쓸 수 없습니다. 요청은 IELTS 채점·PDF 변환 용도로만 제한됩니다.
- **`TUTOR_PASSCODE`** 를 설정하면 앱 상단 입력란에 같은 값을 넣은 사람만 사용할 수 있습니다. 개인용이라면 이걸 켜두는 걸 권합니다.

그래도 불안하면 사이트 이름을 추측하기 어렵게 짓거나, Netlify의 접근 제어 기능을 쓰세요.

## 기능

**밴드 계산기** — 4개 영역 트랙을 관통하는 7.0 목표선. 마커를 끌면 공식 반올림(.25와 .75는 올림)으로 Overall이 실시간 계산됩니다. **합계 27.0이면 Overall 7.0**입니다.

**28일 트래커** — 시험 날짜만 넣으면 실제 요일에 맞춰 일정이 생성됩니다. 셀 채움 높이가 그날 완료율입니다.

**CBT 리딩** — 실제 컴퓨터 시험과 같은 좌우 분할, 20분 타이머, 문항 팔레트. Matching Headings 6문항 + True/False/Not Given 4문항 + Summary Completion 3문항. 제출하면 채점 후 틀린 문항마다 튜터가 함정 구조와 풀이 전략을 설명합니다.

**라이팅 랩** — Task 2 문제 8개, Task 1 차트/표 3개. 4개 채점 기준별 밴드와 *고쳐 쓴 문장*을 받습니다.

**스피킹 랩** — 녹음 후 스크립트를 옮겨 적으면 3개 기준으로 피드백. 발음은 스크립트로 평가할 수 없어 제외됩니다.

**내 문제집(PDF)** — 본인이 보유한 IELTS PDF(예: 케임브리지 공식 기출 17·18·19·20·21)를 올리면, 브라우저 안에서 텍스트를 읽어 AI가 지문·문제·정답을 구조화하고 위 CBT 리딩에 그대로 태웁니다. 그러면 타이머·채점·오답 튜터 해설을 **내 기출 문제로** 쓸 수 있습니다. 자세한 사용법은 아래 별도 섹션 참고.

**빈출 단어장 (간격 반복 + 인출 퀴즈)** — 학술 어휘를 **능동 인출(뜻만 보고 영어 단어를 직접 입력)** 로 테스트하고, **Leitner 간격 반복(SRS)** 으로 복습 주기를 자동 조절합니다. 맞히면 다음 복습이 1→2→4→7→15일로 벌어지고, 틀리면 이번 세션에 다시 나옵니다. ‘오늘 복습’에 나올 단어 수는 대시보드에도 표시됩니다. 단순 암기 리스트보다 유지력이 훨씬 높은 방식입니다.

**자동 오답노트** — 모든 AI 피드백이 원인 분류와 함께 오답노트에 자동 저장되고, 원인 분포 막대에 반영됩니다. 1위 원인이 무엇인지가 다음 주 공부 방향을 결정합니다.

**타이머** — Task 2 40분, 지문당 20분, Speaking Part 2 준비 1분/발화 2분.

## 연습 문제에 대한 정직한 이야기

앱에 들어 있는 리딩 지문과 문제는 **전부 이 앱을 위해 새로 쓴 창작물**입니다. 기출을 그대로 넣는 것은 저작권 문제가 있고, 난이도 보정도 검증되지 않습니다.

따라서 이 CBT 모듈은 **인터페이스 적응과 유형 훈련용**입니다. 점수를 예측하는 용도로는 여전히 **케임브리지 공식 기출**을 쓰세요. 모의고사 점수는 반드시 기출로 측정해서 앱의 모의고사 기록에 넣으시길 권합니다.

그 기출을 **앱 안에서 CBT로 풀고 싶다면** — 케임브리지 문제집을 앱에 내장 배포하는 것은 저작권상 불가능하지만, **본인이 적법하게 구매·보유한 PDF를 직접 올려** 쓰는 것은 아래 「내 문제집(PDF)」 기능으로 가능합니다. 파일은 브라우저 안에서만 처리되고 서버에 저장되지 않습니다.

AI 채점도 마찬가지입니다. 실제 시험관 채점과 상관관계는 있지만 완전히 일치하지 않습니다. **밴드 숫자보다 "고칠 것" 항목을 보세요.** 그쪽이 실제로 점수를 움직입니다.

### 피드백 방식: AI 튜터 / Cambridge 공식

CBT와 라이팅 랩 상단에서 피드백 방식을 고를 수 있습니다.

- **🤖 AI 튜터**: AI가 오답 해설·에세이 채점을 생성합니다(기존 방식).
- **📘 Cambridge 공식**: 업로드한 책 파일에 들어 있는 **공식 정답·오디오 대본·모범답안·시험관 코멘트**를 그대로 보여줍니다(AI 호출 없음). Reading/Listening은 공식 정답과 대본을, Writing은 그 책의 모범답안과 시험관 코멘트를 표시합니다. 이 자료는 **본인이 올린 파일에서 브라우저 안으로만** 읽어와 표시되며, 책에 해당 자료가 없으면 안내가 뜹니다.

## 내 문제집(PDF · ZIP) 불러오기

케임브리지 공식 기출 같은 **본인 소유 파일**을 앱 안에서 실제 CBT처럼 푸는 기능입니다. 두 가지 방식이 있습니다.

- **PDF 한 개** → 그 안의 Reading 지문 하나를 골라 CBT로 변환 (아래 「단일 PDF」).
- **ZIP(책 압축본)** → 책 PDF + 리스닝 오디오를 통째로 올려 **Listening·Reading·Writing·Speaking 전부**를 Test별로 학습 (아래 「ZIP: 4기능 전부」).

### ZIP: 4기능 전부 (예: `Cambridge IELTS 20.zip`)

케임브리지 다운로드본처럼 **책 PDF + 리스닝 오디오(mp3)** 가 함께 든 ZIP을 그대로 올리는 방식입니다. 오디오 파일명은 `T1S1.mp3`(Test 1, Section 1)처럼 `T{테스트}S{섹션}` 규칙이어야 리스닝에 자동 연결됩니다.

1. 「내 문제집(PDF · ZIP)」 패널에서 **PDF · ZIP 파일 선택** → ZIP을 고릅니다.
2. 브라우저가 ZIP을 풀어 **PDF 텍스트 + 오디오**를 인식하고, AI가 책 구조(Test 1~4 × L/R/W/S, 정답·대본 위치)를 분석합니다.
3. **Test × 영역 표**가 나타납니다. 원하는 칸(예: Test 1 · Listening)을 누르면:
   - **Listening** → 해당 Test의 오디오 4개 + 문제가 CBT에 실립니다. 오디오를 듣고 풀어 제출하면 채점 + 틀린 문항 해설(오디오 대본 근거).
   - **Reading** → 3지문+문제가 CBT로.
   - **Writing** → Task 1·2 문제가 **라이팅 랩**에 들어갑니다(작성 후 AI 채점).
   - **Speaking** → Part 1·2·3 질문이 **스피킹 랩**에 들어갑니다.
4. 채점·해설·오답노트는 기존 기능과 동일하게 동작합니다.

**ZIP 방식에서 알아둘 점**
- **메모리**: 책 오디오까지 있는 ZIP은 큽니다(수백 MB). **데스크톱 브라우저를 권장**합니다. 모바일에서는 메모리 부족으로 실패할 수 있습니다.
- **오디오는 저장되지 않습니다**: 리스닝 오디오는 브라우저 메모리에서만 재생되며 localStorage에 저장되지 않습니다. 페이지를 새로고침하면 ZIP을 다시 올려야 합니다.
- **오디오 파일명 규칙**: `T1S1.mp3`~`T4S4.mp3` 형식이라야 Test·Section에 자동 매칭됩니다. 규칙이 다르면 문제는 풀 수 있지만 오디오가 연결되지 않습니다.
- **정답·대본**: 색인이 책 뒤쪽 정답 키·오디오 대본 페이지까지 잡아 함께 보냅니다. 그래야 채점과 리스닝 해설이 정확합니다.
- **큰 책은 시간이 걸립니다**: 색인 1회 + 고른 영역마다 변환 1회씩 AI를 호출합니다. Gemini 무료 티어라면 한 번에 한 영역씩 하는 것을 권합니다.

### 단일 PDF

1. 「내 문제집(PDF · ZIP)」 패널에서 **PDF · ZIP 파일 선택** → PDF를 고릅니다.
2. 브라우저가 페이지별 텍스트를 읽고, 페이지 번호 칩이 나타납니다.
3. **Reading 지문 1개 + 그 문제**가 있는 페이지를 고릅니다. **정답 페이지까지 함께 고르면 채점이 정확**해집니다(정답이 없으면 AI가 지문 근거로 직접 풉니다).
4. **선택 페이지 → AI로 CBT 변환**을 누르면, 아래 「CBT 리딩 연습」에 그 지문·문제가 실립니다.
5. 이후는 기존 CBT와 동일 — 20분 타이머로 풀고, 제출하면 채점 + 틀린 문항 튜터 해설 + 오답노트 자동 저장.
6. 변환한 문제집은 브라우저에 저장되어 다음에 **불러오기**로 다시 풀 수 있고, **샘플 지문으로 되돌리기**로 언제든 원래 연습 지문으로 돌아갑니다.

### 알아둘 점

- **저작권**: 문제집 자체는 앱에 포함하지 않습니다. 본인이 적법하게 구매·보유한 파일만 쓰세요. 파일은 서버에 저장·전송되지 않고 **브라우저 안에서만** 텍스트로 처리됩니다. 구조화를 위해 선택한 페이지의 **텍스트**만 채점 API(Anthropic)로 전송됩니다 — 이는 앱이 에세이를 채점할 때와 동일한 경로입니다.
- **인터넷/의존성**: PDF 텍스트 추출에 [pdf.js](https://mozilla.github.io/pdf.js/), ZIP 해제에 [fflate](https://github.com/101arrowz/fflate)를 CDN(jsdelivr)에서 필요할 때만 불러옵니다. 따라서 이 기능은 인터넷 연결이 필요합니다(폰트·CSS와 동일). CBT 변환은 **AI 튜터가 동작하는 배포**(경로 B/C)에서만 됩니다.
- **스캔본은 안 됩니다**: 텍스트가 없는 이미지 스캔 PDF는 추출이 되지 않습니다. OCR로 텍스트를 입힌 PDF를 쓰세요.
- **한 번에 지문 하나**: 정확도와 비용을 위해 한 번에 지문 1개 분량만 변환하는 것이 좋습니다. 페이지를 너무 많이 고르면(약 4만 자 초과) 경고가 뜹니다. 40문항 풀세트를 원하면 지문 3개를 각각 변환해 번갈아 푸세요.
- **지원 문제 유형**: Matching Headings, True/False/Not Given, Yes/No/Not Given, 객관식(Multiple Choice), 빈칸·요약·문장완성(Summary/Sentence Completion). 표·그림에 의존하는 유형은 텍스트만으로는 재현되지 않을 수 있습니다.
- **AI 변환은 완벽하지 않습니다**: 번호·정답이 어긋나면 원문(선택 페이지 원문 보기)과 대조하세요. 정답 페이지를 함께 넣는 것이 가장 확실합니다.

## 데이터

모든 기록은 **브라우저 localStorage**에 저장됩니다. 서버에 저장되지 않고 계정도 없습니다.

- 기기·브라우저마다 별도 저장되며 동기화되지 않습니다. 한 기기를 정해서 쓰세요
- 시크릿 모드나 브라우저 데이터 삭제 시 사라집니다
- 배포 후 모바일에서 "홈 화면에 추가"를 하면 앱처럼 전체화면으로 실행됩니다

**백업·복원(중요)**: 상단 설정의 **백업 내보내기**로 모든 기록을 JSON 파일로 저장하고, **복원**으로 되돌리거나 다른 기기로 옮길 수 있습니다. 브라우저 데이터가 지워지면 기록도 사라지므로, **주기적으로 백업**하거나 기기를 바꿀 때 백업→복원하세요.

**작성 답안 자동 임시저장**: 라이팅·스피킹에 쓰던 답안은 자동으로 임시저장되어, 새로고침하거나 실수로 나가도 다시 열면 복원됩니다. ‘지우기’를 누르면 삭제됩니다.

**연속 학습**: 대시보드의 ‘연속 학습’은 하루라도 완료 항목이 있으면 이어지는 일수입니다. 매일 조금씩이라도 이어가세요.

AI 튜터에 보내는 내용(작성한 에세이, 스피킹 스크립트, 틀린 문항)은 Anthropic API로 전송되어 채점됩니다.

## 고치기

`index.html` 안의 상수만 바꾸면 됩니다.

| 상수 | 내용 |
|---|---|
| `ROTATION` | 요일별 학습 항목과 소요 시간 |
| `WEEKS` | 주차별 주제·지침·목표 |
| `PASSAGE` / `QUESTIONS` / `HEADINGS` | 기본 샘플 리딩 지문과 문제. 문항 `type`은 `heading` / `tfng` / `ynng` / `mcq` / `gap` 지원 (`mcq`는 문항별 `opts` 배열, 복수 정답은 `a`를 `"답1\|답2"`로). `loadTest()`로 같은 형식의 다른 시험을 갈아끼울 수 있고, 「내 문제집(PDF)」이 이 경로로 동작합니다 |
| `TASK2` / `TASK1` | 라이팅 문제. TASK1의 `chart`는 bar / line / table 지원 |
| `SPEAK` | 스피킹 큐카드 |
| `PRESETS` | 타이머 프리셋 (초) |
| `REF` | 영역별 핵심 기술 |

채점 프롬프트를 바꾸려면 `netlify/functions/tutor.mjs`의 `SYSTEMS`를 수정합니다. 브라우저 폴백용 사본이 `index.html`의 `CLIENT_SYS`에도 있으니 함께 고쳐야 일관됩니다.

`TUTOR_MODEL`을 `claude-opus-4-8`로 바꾸면 채점이 더 정확해지지만 느리고 비쌉니다. Writing 채점만 Opus로 돌리고 싶다면 `tutor.mjs`에서 task별로 모델을 분기하세요.
