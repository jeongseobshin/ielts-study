# IELTS 7.0 · 28일 스프린트

28일 학습 트래커 + CBT 형식 연습 + AI 튜터 피드백 + 자동 오답노트.

프론트엔드는 `index.html` 한 파일이고, AI 튜터만 서버리스 함수 하나를 씁니다.

---

## 배포: 두 가지 경로

AI 튜터를 쓸지에 따라 방법이 갈립니다. **드래그 앤 드롭으로는 AI 튜터가 동작하지 않습니다** — Netlify Drop은 정적 파일만 게시하고 서버 함수를 실행하지 않기 때문입니다.

| | 드래그 앤 드롭 | CLI 또는 Git |
|---|---|---|
| 트래커·밴드 계산기·타이머 | 동작 | 동작 |
| CBT 리딩 (채점까지) | 동작 | 동작 |
| **AI 튜터 피드백** | **안 됨** | 동작 |
| 걸리는 시간 | 1분 | 5분 |

### 경로 A — 드래그 앤 드롭 (AI 없이 먼저 써보기)

1. `ielts-sprint.zip`의 **압축을 풀어** `ielts-sprint` 폴더를 만듭니다
2. https://app.netlify.com/drop 에 그 **폴더를** 끌어다 놓습니다 (zip 그대로 말고 폴더를)
3. 주소가 즉시 발급됩니다

AI 채점 버튼을 누르면 "Netlify에 배포하고 ANTHROPIC_API_KEY를 설정하세요"라는 안내가 뜹니다. 나머지 기능은 전부 정상입니다.

### 경로 B — CLI (AI 튜터 포함, 권장)

```bash
npm install -g netlify-cli
cd ielts-sprint
netlify login
netlify deploy --prod
```

배포 후 API 키를 등록합니다.

```bash
netlify env:set ANTHROPIC_API_KEY sk-ant-여기에-본인-키
netlify deploy --prod          # 환경변수 반영을 위해 한 번 더
```

### 경로 C — Git 연동

GitHub에 올리고 Netlify에서 "Add new project → Import an existing project"로 연결합니다.

| 항목 | 값 |
|---|---|
| Build command | *(비워둠)* |
| Publish directory | `.` |
| Functions directory | `netlify/functions` *(netlify.toml에 이미 지정됨)* |

## AI 튜터 설정

### 1. API 키 발급

https://console.anthropic.com 에서 API 키를 만듭니다. **Claude 앱 구독(Pro/Max)과는 별개의 유료 종량제**입니다. 콘솔에서 크레딧을 충전해야 동작합니다.

### 2. 환경변수 등록

Netlify → Site configuration → Environment variables

| 변수 | 필수 | 설명 |
|---|---|---|
| `ANTHROPIC_API_KEY` | 필수 | 발급받은 키 |
| `TUTOR_MODEL` | 선택 | 기본 `claude-sonnet-5`. 모델 오류가 나면 현재 사용 가능한 이름으로 교체 |
| `TUTOR_PASSCODE` | 선택 | 설정하면 이 값을 아는 사람만 튜터를 쓸 수 있음 |

환경변수를 바꾼 뒤에는 **반드시 재배포**해야 반영됩니다.

### 3. 비용 감각

Writing 에세이 1편 채점은 대략 입력 1천 토큰 + 출력 1~2천 토큰 수준입니다. 하루 에세이 2편 + 리딩 오답 해설을 28일 내내 돌려도 통상 몇 달러 범위입니다. 다만 요금은 바뀔 수 있으니 https://claude.com/pricing 에서 확인하세요.

### 4. 공개 URL이 걱정된다면

이 사이트를 배포하면 주소를 아는 사람은 누구나 사용자님 API 키로 튜터를 호출할 수 있습니다. 두 가지 방어책이 들어 있습니다.

- **시스템 프롬프트가 서버에 고정**되어 있습니다. 클라이언트는 `task`와 데이터만 보내며, 프롬프트를 바꿔 범용 챗봇으로 쓸 수 없습니다. 요청은 IELTS 채점 세 종류로만 제한됩니다.
- **`TUTOR_PASSCODE`** 를 설정하면 앱 상단 입력란에 같은 값을 넣은 사람만 사용할 수 있습니다. 개인용이라면 이걸 켜두는 걸 권합니다.

그래도 불안하면 사이트 이름을 추측하기 어렵게 짓거나, Netlify의 접근 제어 기능을 쓰세요.

## 기능

**밴드 계산기** — 4개 영역 트랙을 관통하는 7.0 목표선. 마커를 끌면 공식 반올림(.25와 .75는 올림)으로 Overall이 실시간 계산됩니다. **합계 27.0이면 Overall 7.0**입니다.

**28일 트래커** — 시험 날짜만 넣으면 실제 요일에 맞춰 일정이 생성됩니다. 셀 채움 높이가 그날 완료율입니다.

**CBT 리딩** — 실제 컴퓨터 시험과 같은 좌우 분할, 20분 타이머, 문항 팔레트. Matching Headings 6문항 + True/False/Not Given 4문항 + Summary Completion 3문항. 제출하면 채점 후 틀린 문항마다 튜터가 함정 구조와 풀이 전략을 설명합니다.

**라이팅 랩** — Task 2 문제 8개, Task 1 차트/표 3개. 4개 채점 기준별 밴드와 *고쳐 쓴 문장*을 받습니다.

**스피킹 랩** — 녹음 후 스크립트를 옮겨 적으면 3개 기준으로 피드백. 발음은 스크립트로 평가할 수 없어 제외됩니다.

**자동 오답노트** — 모든 AI 피드백이 원인 분류와 함께 오답노트에 자동 저장되고, 원인 분포 막대에 반영됩니다. 1위 원인이 무엇인지가 다음 주 공부 방향을 결정합니다.

**타이머** — Task 2 40분, 지문당 20분, Speaking Part 2 준비 1분/발화 2분.

## 연습 문제에 대한 정직한 이야기

앱에 들어 있는 리딩 지문과 문제는 **전부 이 앱을 위해 새로 쓴 창작물**입니다. 기출을 그대로 넣는 것은 저작권 문제가 있고, 난이도 보정도 검증되지 않습니다.

따라서 이 CBT 모듈은 **인터페이스 적응과 유형 훈련용**입니다. 점수를 예측하는 용도로는 여전히 **케임브리지 공식 기출**을 쓰세요. 모의고사 점수는 반드시 기출로 측정해서 앱의 모의고사 기록에 넣으시길 권합니다.

AI 채점도 마찬가지입니다. 실제 시험관 채점과 상관관계는 있지만 완전히 일치하지 않습니다. **밴드 숫자보다 "고칠 것" 항목을 보세요.** 그쪽이 실제로 점수를 움직입니다.

## 데이터

모든 기록은 **브라우저 localStorage**에 저장됩니다. 서버에 저장되지 않고 계정도 없습니다.

- 기기·브라우저마다 별도 저장되며 동기화되지 않습니다. 한 기기를 정해서 쓰세요

AI 튜터에 보내는 내용(작성한 에세이, 스피킹 스크립트, 틀린 문항)은 Anthropic API로 전송되어 채점됩니다.

## 고치기

`index.html` 안의 상수만 바꾸면 됩니다.

| 상수 | 내용 |
|---|---|
| `ROTATION` | 요일별 학습 항목과 소요 시간 |
| `WEEKS` | 주차별 주제·지침·목표 |
| `PASSAGE` / `QUESTIONS` / `HEADINGS` | 리딩 지문과 문제 (지문 추가 시 같은 형식으로) |
| `TASK2` / `TASK1` | 라이팅 문제. TASK1의 `chart`는 bar / line / table 지원 |
| `SPEAK` | 스피킹 큐카드 |
| `PRESETS` | 타이머 프리셋 (초) |
| `REF` | 영역별 핵심 기술 |

채점 프롬프트를 바꾸려면 `netlify/functions/tutor.mjs`의 `SYSTEMS`를 수정합니다. 브라우저 폴백용 사본이 `index.html`의 `CLIENT_SYS`에도 있으니 함께 고쳐야 일관됩니다.

`TUTOR_MODEL`을 `claude-opus-4-8`로 바꾸면 채점이 더 정확해지지만 느리고 비쌉니다. Writing 채점만 Opus로 돌리고 싶다면 `tutor.mjs`에서 task별로 모델을 분기하세요.
